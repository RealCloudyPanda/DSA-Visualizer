# DSA Visualizer

Step-through visualizers for the data structures and algorithms that come up in coding interviews: every NeetCode 150 pattern, classic sorts and searches, graphs, DP, bit tricks and a few ML extras.

**Live:** https://realcloudypanda.github.io/DSA-Visualizer/

## Features
- 52 visualizers, each with highlighted pseudocode, live variables, a clickable step log and related LeetCode problems
- Your own input or random input, input history, and a reset to the example
- Play, pause, step, scrub, speed control, loop and auto-play
- Shareable links that open at the exact input and step
- Time and space complexity badges and a color legend
- Light, dark or system theme, custom accent and highlight colors, text size, visual zoom and layout
- Favorites, "learned" tracking with progress, and a home page to continue where you left off
- Searchable, collapsible sidebar, focus mode, a mobile drawer and swipe-to-step
- Settings and progress are saved in your browser

## Keyboard shortcuts
| Key | Action |
|---|---|
| Space | Play / pause |
| ← / → (Shift for 10) | Step |
| Home / End | First / last step |
| R | Random input |
| J / K | Next / previous visualizer |
| [ / ] | Slower / faster |
| / | Search |
| M / L | Mark learned / favorite |
| T / S / F | Theme / settings / focus mode |
| ? | Show all shortcuts |
